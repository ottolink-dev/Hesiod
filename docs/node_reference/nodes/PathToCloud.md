
PathToCloud Node
================


PathToCloud convert a Path to a set of points (Cloud).



![img](../../images/nodes/PathToCloud_settings.png)


## Category


Geometry/Path
## Inputs

|Name|Type|Description|
| :--- | :--- | :--- |
|path|Path|Input path.|

## Outputs

|Name|Type|Description|
| :--- | :--- | :--- |
|cloud|Cloud|Output cloud.|
