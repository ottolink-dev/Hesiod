
Abs Node
========


Apply an absolute function to every values.



![img](../../images/nodes/Abs_settings.png)


## Category


Math/Base
## Inputs

|Name|Type|Description|
| :--- | :--- | :--- |
|input|VirtualArray|Input heightmap.|

## Outputs

|Name|Type|Description|
| :--- | :--- | :--- |
|output|VirtualArray|Output heightmap.|

## Parameters

|Name|Type|Description|
| :--- | :--- | :--- |
|Vertical Shift|Float|Reference value for the zero-equivalent value of the absolute value.|
