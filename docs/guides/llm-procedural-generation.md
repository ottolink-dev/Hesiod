# Driving Procedural Generation with an LLM

Use the `hesiod-generate` Claude Code skill to author, validate, and batch-render Hesiod terrain graphs from natural language descriptions. The skill lives at `.claude/skills/hesiod-generate/SKILL.md` and is designed for game-dev workflows: seed sweeps, biome exploration, and large tiled maps. See [Automation & Batch / Headless Operation](batch-headless.md) for the full CLI and spec reference.
